Aspirations, Investment, and the Inverted U (AK and CRRA, ratio form)

Sumedh Ramakrishna | Alfred Weber Institute, Heidelberg University | November 2025
Constrained Optimization Loss Function Formulation Empirical Microdata High Dimensional Fixed Effects Non Linear Regression R / Stata
Applied machine learning and quantitative modeling: Structuring an asymmetric reference dependent objective function, solving for critical bifurcation boundaries, and verifying non linear responses using large scale panel microdata.

Objective Function and System Constraints

In this research, I formulate an optimization problem where agents make dynamic capital allocation decisions subject to forward looking reference targets. Each agent begins with scalar resource endowment \(y > 0\) and allocates it between baseline consumption \(c\) and capital investment \(k\). The production transition kernel is modeled linearly as \(f(k) = \rho k = z\) with productivity parameter \(\rho > 1\). The state budget boundary is defined by:

$$y = c + k, \quad k \ge 0, \quad f'(k) > 0, \quad f''(k) \le 0$$

Preferences are structured using an asymmetric loss function anchored around an exogenous reference target \(a\). The global objective balances immediate utility, future baseline return, and a piecewise penalty reward operator:

$$U(c, k, a) = u(c) + \delta [w_0(f(k)) + \pi_G W_G((f(k) - a)_+) - \pi_L W_L((a - f(k))_+)]$$

Here \(u\), \(w_0\), \(W_G\), and \(W_L\) are concave utility mappings sharing common relative risk aversion elasticity \(\sigma \in (0, 1)\), \(\delta > 0\) represents the intertemporal discount parameter, and \(\pi_L > \pi_G \ge 0\) defines empirical loss aversion where shortfalls are penalized more heavily than gains.

Scale Normalization and Structural Regimes

To eliminate scale dependence and allow clean generalization across heterogeneous resource endowments, I normalize the decision variables into scale invariant ratios. I define the growth factor as \(g = z / y\), the reference ratio as \(r = a / y\), and the investment rate as \(i = k / y = g / \rho\). This transforms the problem into maximizing a reduced piecewise objective:

$$\tilde{U}(g, r) = \left(1 - \frac{g}{\rho}\right)^{1-\sigma} + \delta [g^{1-\sigma} + \pi_G (g - r)_+^{1-\sigma} - \pi_L (r - g)_+^{1-\sigma}], \quad g \in [0, \rho]$$

First order optimization conditions reveal that the agent parameter space partitions into two distinct operating regimes around an optimal bifurcation threshold \(r^* > 1\):

  • Satisfied Regime \( (g \ge r) \) for \( r \le r^* \): The target lies within reachable budget bounds. Here the first order condition evaluates along the positive reward domain, yielding a positive gradient \(\partial g^* / \partial r > 0\) where higher aspiration goals incentivize greater capital allocation.
  • Frustrated Regime \( (g < r) \) for \( r > r^* \): When the reference target exceeds threshold \(r^*\), attaining it demands unsustainable sacrifice of base consumption. The loss penalty dominates, resulting in a negative gradient \(\partial g^* / \partial r < 0\) where excessive target distance causes an abandonment effect and depresses investment.

Combining both regimes analytically establishes a global inverted U topology for equilibrium investment:

$$k^*(y, a) = \frac{y}{\rho} g^*\left(\frac{a}{y}\right), \quad i^*(r) = \frac{g^*(r)}{\rho}$$

Empirical Validation and High Dimensional Controls

I tested whether this non linear optimization pattern holds in real world microdata using \(N = 4{,}651\) longitudinal household records from the Indonesian Family Life Survey. The target metric measures human capital investment, specified as:

$$\text{Target Variable} = 100 \times \log(\text{Education expenditure per capita})$$

To evaluate non linearity and prevent spatial confounding from unobserved community infrastructure, I estimated a quadratic polynomial specification combined with high dimensional Kecamatan neighborhood fixed effects and cluster robust standard errors:

$$\text{Target}_i = \beta_0 + \beta_1 r_i + \beta_2 r_i^2 + \Gamma X_i + \alpha_{\text{kecamatan}} + \varepsilon_i$$

Machine Learning and Quantitative Insights

  • Statistical Significance: Across all specifications, the linear coefficient remains positive and significant (\(\beta_1 \approx 34.52\), \(p < 0.01\)) while the quadratic penalty term is negative and significant (\(\beta_2 \approx -4.33\), \(p < 0.05\)), confirming the inverted U curve.
  • Optimal Threshold Calculation: Differentiating the response function \(\frac{\partial \text{Target}}{\partial r} = \beta_1 + 2\beta_2 r = 0\) yields the empirical turning point at \(r^* = -\frac{\beta_1}{2\beta_2} \approx 3.98\) to \(4.48\). Targets within this ratio accelerate resource allocation, whereas targets set beyond this boundary trigger motivation breakdown and reduce capital commitments.
  • Applied Data Science Relevance: Demonstrates experience in objective formulation, modeling asymmetric loss functions, processing large scale survey tables, and implementing high dimensional fixed effects models relevant to behavioral modeling and predictive underwriting.
