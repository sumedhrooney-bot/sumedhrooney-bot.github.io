Parental Aspirations and Children's Education: Econometric Evidence from Indonesia

Sumedh Ramakrishna | Master Thesis | Heidelberg University | 2025
Machine Learning Optimization Feature Engineering Non Linear Regression R / Stata / Python
Quantitative modeling and microeconometrics: Formulating a reference-dependent utility model with loss aversion, deriving the analytical conditions for an inverted-U investment response, and testing the non-linear relationship using household panel data from the IFLS.

Objective Function and System Constraints

I model household investment decisions as a constrained non linear optimization problem. Each agent starts with a scalar resource endowment \(y > 0\) and determines the optimal resource allocation between current consumption \(c\) and capital investment \(k\). Investment yields a next period return \(z = f(k)\) governed by a linear capital production kernel \(f(k) = \rho k = z\) with productivity parameter \(\rho > 1\). The budget constraint is defined as:

$$y = c + k, \quad k \ge 0, \quad f'(k) > 0, \quad f''(k) \le 0$$

I define an asymmetric reference dependent utility objective anchored around a forward target \(a\). The objective balances baseline consumption, future expected capital return, and a piecewise gain loss penalty term:

$$U(c, k, a) = u(c) + \delta [w_0(f(k)) + \pi_G W_G((f(k) - a)_+) - \pi_L W_L((a - f(k))_+)]$$

Here \(u\), \(w_0\), \(W_G\), and \(W_L\) are concave mappings with common curvature \(\sigma \in (0, 1)\), \(\delta > 0\) represents the discount weight, and \(\pi_L > \pi_G \ge 0\) imposes an asymmetric penalty structure where target shortfalls are penalized more severely than target gains.

Scale Normalization and Analytical Regimes

To make decision variables scale invariant across agents, I normalize variables into continuous ratios: the growth factor \(g = z / y\), the aspirations ratio \(r = a / y\), and the investment share \(i = k / y = g / \rho\). This transforms the system into maximizing the following reduced piecewise objective:

$$\tilde{U}(g, r) = \left(1 - \frac{g}{\rho}\right)^{1-\sigma} + \delta [g^{1-\sigma} + \pi_G (g - r)_+^{1-\sigma} - \pi_L (r - g)_+^{1-\sigma}], \quad g \in [0, \rho]$$

First order optimization conditions partition the agent parameter space into two distinct operating regimes around an optimal bifurcation threshold \(r^* > 1\):

  • Satisfied Regime \((g \ge r)\) for \(r \le r^*\): The target is mathematically accessible within the agent budget envelope. The first order condition evaluates along the positive reward domain, resulting in a positive gradient \(\partial g^* / \partial r > 0\) where higher aspiration goals incentivize greater capital allocation.
  • Frustrated Regime \((g < r)\) for \(r > r^*\): When the target ratio exceeds threshold \(r^*\), attaining it demands an unsustainable sacrifice of base consumption. The loss penalty dominates, causing a negative gradient \(\partial g^* / \partial r < 0\) where excessive target distance causes an abandonment effect and depresses investment.

Combining both regimes produces a global inverted U topology for equilibrium investment:

$$k^*(y, a) = \frac{y}{\rho} g^*\left(\frac{a}{y}\right), \quad i^*(r) = \frac{g^*(r)}{\rho}$$

Feature Engineering and Regression Specification

I trained and validated this model on longitudinal microdata from the Indonesian Family Life Survey (IFLS 5, \(N = 4{,}651\)). To measure household capital allocation, I engineered a continuous target variable:

$$\text{Target Variable } y_h = 100 \times \log(\text{Education expenditure per capita})$$

Using survey responses where individuals evaluate their current position on a 1 to 6 economic ladder alongside their expected position 5 years in the future, I constructed the continuous aspirations ratio feature:

$$\text{Aspirations Ratio } r_h = \frac{\text{Economic step in future}_h}{\text{Economic step today}_h}$$

To model non linearity and eliminate spatial confounding from unobserved community infrastructure, I estimated a quadratic polynomial specification combined with high dimensional Kecamatan neighborhood fixed effects and cluster robust standard errors at the enumeration area level:

$$y_h = \beta_0 + \beta_1 r_h + \beta_2 r_h^2 + \sum_{s=2}^{6} \beta_{3s} \{ \text{step}_h = s \} + X_h'\theta + Z_h'\gamma + \alpha_{\text{kecamatan}} + \varepsilon_h$$

Model Evaluation and Quantitative Insights

  • Non Linear Validation: In the full model, the linear coefficient is positive and statistically significant (\(\beta_1 = 34.518\), \(p < 0.01\)) while the quadratic penalty term is negative and statistically significant (\(\beta_2 = -4.334\), \(p < 0.05\)). A Wald test confirms joint significance (\(F = 5.300\), \(p = 0.005\)), empirically validating the non linear inverted U curve.
  • Optimal Inflection Boundary: Solving the derivative \(\frac{\partial y_h}{\partial r_h} = \beta_1 + 2\beta_2 r_h = 34.518 - 8.668 r_h = 0\) identifies the inflection boundary at \(r^* = -\frac{\beta_1}{2\beta_2} \approx 3.98\). Moving the aspirations ratio from 1 to 2 produces a 26 percent increase in investment, while expanding targets beyond a ratio of 4 causes motivation breakdown.
