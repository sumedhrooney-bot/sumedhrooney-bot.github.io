The Existential Life Coach: A Local RAG Pipeline

Tech Stack: Python, LangChain, Chroma DB, Streamlit, Meta Llama 3.2, Hugging Face Embeddings

A privacy-first, 100% local Retrieval-Augmented Generation (RAG) web application that solves mundane modern grievances using the dramatic theories of 19th-century existential philosophers.

Project Overview

This project was engineered to demonstrate a cost-optimized, privacy-centric AI architecture. By bypassing paid cloud APIs like OpenAI, the system performs all data ingestion, embedding, and natural language generation entirely on local hardware with zero inference costs.

Architecture & Implementation

  • Vector Database & ETL Pipeline: Built a custom document ingestion script utilizing PyPDF to extract and chunk dense 19th-century philosophical texts (Nietzsche, Sartre, Kant, Schopenhauer). The text data was embedded into a persistent local Chroma database using Hugging Face sentence transformers running on the CPU.
  • Local LLM Orchestration: Integrated Meta’s Llama 3.2 model via Ollama as the primary generation engine. The system retrieves the most relevant philosophical chunks using cosine similarity and instructs the LLM to adopt a specific, highly dramatic persona.
  • Frontend UI: Wrapped the LangChain execution logic in a responsive, cached Streamlit web interface for interactive user querying.
